# 2026 AI Training Demand Dashboard

초등·중등·고등 AI·디지털 활용 선도교사 후속연수 수요조사 대시보드입니다.

## 공개 주소

GitHub Pages 주소는 저장소와 계정에 따라 다음 형식으로 발행됩니다.

`https://<GitHub사용자명>.github.io/2026-ai-training-dashboard/`

## 파일 안내

- `index.html`: 학교급별 대시보드 선택 화면
- `elementary_ai_training_demand_dashboard_v2.html`: 초등학교 대시보드
- `middle_school_ai_training_demand_dashboard.html`: 중학교 대시보드
- `high_school_ai_training_demand_dashboard.html`: 고등학교 대시보드

각 대시보드는 데이터, 스타일, 인터랙션을 하나의 HTML 파일에 포함한 정적 페이지입니다. 별도 서버, 빌드 도구, 데이터베이스, 외부 API가 필요하지 않습니다.

## GitHub Pages 설정

저장소의 **Settings → Pages**에서 다음을 선택합니다.

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

배포 후 `index.html`이 기본 페이지로 열립니다.

## 데이터 및 공개 검토

게시 전 공개 가능한 집계 데이터와 대표 응답만 포함되어 있는지 확인하세요. 개인 식별 정보가 포함된 원자료는 이 저장소에 올리지 않습니다.
